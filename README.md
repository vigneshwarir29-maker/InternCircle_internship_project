# Front-End Internship Projects

Five beginner front-end projects built with plain HTML, CSS and JavaScript. No frameworks or build tools needed.

## Projects

| # | Project | File | Key concepts |
|---|---------|------|--------------|
| 1 | Personal Portfolio Landing Page | `project1-portfolio.html` | Semantic HTML5, Flexbox & Grid, responsive design |
| 2 | Interactive To-Do List | `project2-todo.html` | DOM manipulation, click & Enter key events, LocalStorage |
| 3 | Responsive Pricing Cards | `project3-pricing.html` | CSS transitions, hover transforms, JS billing toggle, badge ribbons |
| 4 | Live Weather Dashboard | `project4-weather.html` | `fetch` with async/await, dynamic DOM injection, input validation, error states |
| 5 | Mini E-Commerce App | `project5-shop.html` | Rendering from JS objects, cart count & total, modal checkout preview |

## Features

**1. Portfolio**
- Header with name, title and social links
- About and Skills sections
- Skills grid that adapts to screen size

**2. To-Do List**
- Add tasks with the button or the Enter key
- Click a task to mark it complete
- Delete tasks
- Tasks persist after page reload

**3. Pricing Cards**
- Monthly / Yearly toggle switch
- Cards lift on hover
- "Popular" and "Best Value" badges

**4. Weather Dashboard**
- Search any city
- Current temperature and weather icon
- 5-day forecast
- Handles empty input, unknown cities and network errors
- Uses the free [Open-Meteo API](https://open-meteo.com/) (no API key required)

**5. Mini Shop**
- Products rendered from a JavaScript array
- Live item count and total price
- Checkout modal showing an order preview

## How to Run

1. Download or clone this repository.
2. Double-click any `.html` file to open it in your browser.

Project 4 needs an internet connection to fetch weather data.

## Deploying (free)

**GitHub Pages**
1. Push the files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under "Branch", choose `main` and `/ (root)`, then save.
4. Your site will be at `https://<username>.github.io/<repo>/project1-portfolio.html`.

**Netlify Drop**
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the folder containing the files.
3. Copy the generated link.
